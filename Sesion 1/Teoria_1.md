SQL (Structured Query Language) es un lenguaje utilizado para gestionar y manipular bases de datos relacionales. 
Permite realizar diversas operaciones sobre los datos almacenados en una base de datos, como:

- consultar información
- actualizar registros
- insertar nuevos datos
- eliminar información. 

Un lugar donde puedes almacenar una gran cantidad de información de manera organizada.

Las herramientas encargadas de proveer el lugar donde almacenar estos datos son conocidas como servidores de bases de datos y son básicamente un almacén gigante de información digital. 

## ¿Qué es un gestor de bases de datos? 
Se puede pensar como el encargado o administrador de la biblioteca digital de información

Se asegura de que la información esté organizada de manera adecuada para que sea fácil de buscar y encontrar. También se encarga de proteger la información para que solo las personas autorizadas puedan acceder a ella. Además, el gestor de bases de datos ayuda a garantizar que la información se guarde de manera segura y que no se pierda en caso de que ocurra algún problema.

-  Gestores de bases de datos NoSQL.
-  Gestores de bases de datos en memoria

## Estructura

Las bases de datos relacionales organizan toda la información en tablas; las tablas contienen campos y registros(representan una entidad única en la tabla)

## comandos SQL
- comandos de consulta (para recuperar datos)
- comandos de manipulación de datos (para agregar, modificar o eliminar datos)
- comandos de definición de datos (para definir la estructura de la base de datos)
- comandos de control de datos (para controlar los privilegios de acceso, transacciones, etc.)

Una de las principales tareas de un gestor de bases de datos es extraer información de las tablas que se encuentran dentro de una base de datos. Otra forma de llamar a las bases de datos contenidas en un servidor, es esquema.

A la tarea de obtener datos de las tablas de un esquema se les conoce como consultas.

## Condicionales
En SQL, la cláusula WHERE se utiliza para filtrar los registros devueltos por una consulta basándose en una condición específica. 

<condición>. Es una expresión lógica que debe evaluarse como verdadera o falsa para cada registro. Esta condición puede incluir operadores relacionales (como "=", "<", ">", "<=", ">=", "!=" o "<>":, etc.) y operadores lógicos (como "AND", "OR", "NOT"). 

Los operadores lógicos se utilizan para combinar múltiples condiciones y evaluar si se cumplen todas o alguna de ellas.
