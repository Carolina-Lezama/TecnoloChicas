# Bases de datos en ciencia de datos
## Tipos de bases de datos utilizadas:
- Relacionales (SQL). Estructuradas, utilizadas para almacenar datos tabulares.
- NoSQL. Flexibles, utilizadas para datos no estructurados o semiestructurados, como documentos JSON en MongoDB.
- Data Warehouses. Almacenan grandes volúmenes de datos históricos para análisis.
- Data lakes. Almacenan datos en su forma nativa, estructura o no estructurada.
